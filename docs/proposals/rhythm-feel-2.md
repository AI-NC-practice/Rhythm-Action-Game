# 제안서 2: 리듬감 다시 살리기 (beta1-1)

- 상태: **사용자 검토 대기 (2026-11-15)**
- 사용자 의견 (B43 테스트 빌드 뒤)
  - 노드를 맞췄을 때 나는 소리가 맛이 없다.
  - 상대와 싸울 때 나는 소리도 맛이 없다.
  - 슬로우 기능이 원래 있지 않았나?
  - 곡이 멈추고 패턴을 입력하는 부분이 있으면 멋있을 것 같다.
  - 리듬게임인데 리듬감이 많이 부족하다.

## 0. 지금 상태 진단

| 무엇 | 지금 | 왜 맛이 없나 |
|---|---|---|
| 노드 소리 (히트사운드, B14) | 코드로 만든 장구 흉내 소리 4종 | 곡의 실제 장구·꽹과리와 음색이 달라 "따로 노는 장난감 소리"로 들린다. 곡도 같은 박에 장구를 쳐서 소리가 묻힌다. |
| 전투 소리 | 코드로 만든 금속음·저음·바람(MetalClang, LowBoom, Whoosh 등) | 진짜 칼 소리가 아니다. 휘두름 → 부딪힘의 "쉭-챙" 순서가 박에 맞춰 나오지 않는다. |
| 슬로모션 | **있다.** 모두 PERFECT로 한 판에 **13번** 걸림(처형·윈드밀은 항상, 사건·전투 PERFECT는 16박에 한 번까지). 화면만 0.3배로 0.4초 | 0.4초로 짧고 **음악은 그대로 크게 흘러서** 느려진 느낌이 안 난다. |
| 리듬 신호 | 판정 원이 줄어드는 것 + 곡 | 화면이 박에 맞춰 뛰지 않고(박 펄스 없음), 언제 누를지 귀로 알려 주는 예고음도 없다(제안서 1의 2.1-2, 2.2-4~7은 아직 안 함). |

## 1. 노드 소리를 "곡의 한 타"로 (가장 먼저)
- **진짜 장구·꽹과리 소리로 바꾼다.** 곡에 쓴 공유마당 장구·꽹과리 녹음에서 잘라 쓴다(이미 받은 재료, 추가 비용 없음).
  - PERFECT: 장구 "덩"(궁편+채편 실제 녹음) + 꽹과리 "쨍" 짧게
  - NORMAL: 장구 "덕"
  - FAIL: 북 "턱"(둔하게), 원 없이 누름: 아주 작은 채 소리
- **곡에서 그 박의 장구를 비운다.** 지금은 곡이 판정 박마다 장구를 쳐서 히트사운드와 겹친다. 대신 곡에는 "준비" 소리(꽹과리 작게)만 두고, **"덩"은 플레이어가 쳐야 나는 소리**가 되게 한다. 놓치면 그 박이 비어서 "놓쳤다"가 귀로 느껴진다(리듬게임 키음 방식, DJMAX).
- **누르는 순간 음악을 아주 잠깐(0.08초, −3 dB) 눌러** 히트사운드가 튀어나오게 한다.

## 2. 전투 소리를 진짜 칼 소리로 (B40 일부 앞당김)
- 칼 휘두름 "쉭", 칼끼리 부딪힘 "챙", 베임, 발차기 타격, 쓰러짐을 실제 녹음으로 바꾼다.
- **박에 맞춘 순서:** 적 공격이 오면 판정 반 박 전에 "쉭"(휘두름), 판정 박에 "챙"(막음) 또는 "퍽"(맞음). 소리만으로 박이 들리게 한다.
- 재료 후보: 공유마당 효과음(영화 효과음 시리즈 등), Mixkit(로그인 없이 무료). 고르면 파일 목록을 보여 드리고 승인받고 받는다.

## 3. 슬로모션을 "느껴지게"
- 슬로모션 동안 **음악이 물속처럼 먹먹해지고(저역 통과) 작아졌다가** 끝나면 다시 터진다. 박자 시계는 그대로라 판정은 어긋나지 않는다(GDD 4.2 유지).
- 처형·윈드밀 마무리는 심장박동 "쿵" + 시간이 늘어나는 소리를 넣는다.
- 길이 0.4초는 GDD 값이라 그대로 두고(바꾸려면 따로 정함), 소리로 체감을 키운다.

## 4. 멈춤 패턴: "합" 주고받기 (새 기능)
- **곡이 멈추고**(심장박동·낮은 울림만 남음) **상대가 1마디 리듬을 먼저 보여 준다**: 화살표가 그 리듬대로 하나씩 켜지며 장구 소리를 낸다(예: 덩-덕-덩덩).
- **바로 다음 마디에 플레이어가 같은 리듬으로 받아친다.** 판정 원이 같은 자리에 같은 박으로 나온다. 다 맞추면 곡이 "쾅" 하고 다시 터진다(리듬 세상·파라파 방식).
- 자리: 챕터마다 한 번, 큰 전투 직전(포위 전투 시작, 무사 결투의 단계 사이 "칼 겨루기"). 무사와 칼로 "합"을 주고받는 장면과 잘 맞는다.
- 패턴은 2~4개 판정, 반 박 포함. 실패하면 체력 −1, 되감기는 없다.
- 차트에 새 사건 종류(call_response)를 넣고, 곡 생성기(make-song.py)가 그 자리를 비우고 부르는 소리를 넣는다.

## 5. 화면이 박에 맞춰 숨 쉬게 (제안서 1의 미뤄 둔 것)
- **박 펄스:** 박마다 판정 원 테두리·HUD·화면 가장자리가 살짝 커졌다 돌아온다(마디 첫 박은 더 크게).
- **예고음:** 판정 원이 나타나면 남은 박마다 작은 "틱"(설정에서 끄기).
- **발걸음·카메라를 박에 맞춤:** 1박 = 한 걸음, 카메라가 박마다 살짝 출렁인다.

## 6. 진행 순서 제안
1. **노드 소리 실제 장구 + 곡에서 그 박 비우기 + 순간 덕킹** (1장) — 가장 효과가 크고 재료가 이미 있다.
2. **박 펄스 + 예고음** (5장)
3. **멈춤 패턴 "합"** (4장)
4. **슬로모션 체감** (3장)
5. **전투 소리 실제 녹음** (2장) — 재료를 찾아 승인받아야 한다.

각 단계마다 테스트 빌드로 들어 보고 다음으로 간다.
