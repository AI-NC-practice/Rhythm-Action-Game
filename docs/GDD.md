## 1. 개요
| 항목 | 내용 |
|---|---|
| 제목 | Rhythm-Action-Game |
| 장르 / 시점 | 리듬 액션 + 파쿠르, 1인칭 3D (전신이 있는 1인칭: 손·발·다리·몸통이 화면에 보임) |
| 엔진 | Unity 6000.4.0f1, URP, Windows PC |
| 그래픽 | 만화풍 (툰 셰이딩 + 외곽선) |
| 에셋 | VARCO 3D (GLB, 삼각형 5,000개 이하). 사람 캐릭터는 리깅 + 애니메이션 (VARCO Rig/Animate + Mixamo) |
| 사운드 | 개발 중: 120 BPM 메트로놈(코드로 생성). 이후: AI 생성곡(Suno 등, 국악 퓨전, BPM 고정, 보컬 없음)으로 교체 |
| 한 줄 요약 | 조선의 골목과 기와지붕 위를 자동으로 달리며, 박자에 맞춰 방향키를 눌러 장애물을 넘고 칼과 창을 든 적을 쓰러뜨린다 |
| 플레이 시간 | 스테이지 1개, 기본 속도 기준 약 3분 |

## 2. 핵심 루프
자동 달리기 → 장애물/적 등장 → 화면이 회색으로 바뀌고 카메라 줌인 + 판정 원 등장 → 박자에 맞춰 방향키 입력
→ PERFECT / NORMAL / FAIL 판정 → 결과별 동작 연출 + 속도 변화 → 다시 달리기 → … → 성문 위 결전 → 결과 화면

## 3. 조작
| 입력 | 동작 |
|---|---|
| ↑ | 뛰어넘기, 뛰어오르기, 지붕 건너뛰기 / 전투: 받아 막기, 마무리 공격 |
| ↓ | 미끄러져 통과, 뛰어내려 구르기 / 전투: 숙여 피하기 |
| ← / → | 옆으로 피하기, 왼쪽/오른쪽 벽타기 / 전투: 옆으로 비키기 |
| Esc | 일시정지 |
| 마우스 왼쪽 클릭 / Enter | 메뉴 선택 |

- 이동은 자동이다. 플레이어는 방향키만 누른다.
- 판정 창마다 눌러야 할 키는 하나다. 화면의 버튼 아이콘에 그 키가 표시된다.

## 4. 시스템

### 4.1 박자와 속도
- 기준 BPM: **120** (1박자 = 0.5초, 속도 배율 1.0일 때).
- 속도 배율 `s`: 시작 **1.00**, 최소 **1.00**, 최대 **1.30**.
- 판정 결과에 따른 속도 변화:
  | 판정 | 속도 변화 |
  |---|---|
  | PERFECT | `s = min(s + 0.05, 1.30)` |
  | NORMAL | 변화 없음 |
  | FAIL | `s = max(s × 0.8, 1.00)` |
- 속도 배율은 음악과 이동에 **함께** 적용된다.
  - 음악 재생 속도 = `s`. 음 높이는 AudioMixer Pitch Shifter로 `1/s`만큼 보정한다(다람쥐 소리 방지).
  - 달리기 속도 = **5 m/s × s**. 따라서 1박자에 이동하는 거리는 속도와 관계없이 **2.5 m**로 항상 같다.
  - 판정 원이 줄어드는 시간도 박자 기준(2박자)이라 실제 초는 `1.0초 / s`로 짧아진다 → 빨라질수록 어려워진다.
- 박자 시계는 `AudioSettings.dspTime` 기준으로 계산한다(프레임 시간과 무관).
- 곡이 스테이지보다 먼저 끝나면 곡을 처음부터 반복한다(재도전으로 길어질 수 있음).

### 4.2 판정 (리듬 QTE)
- **등장:** 목표 시점 **2박자 전**에 판정 원이 나타난다.
  - 화면 채도 −60% (회색빛), 0.15초 동안 전환.
  - 카메라 FOV 70° → 58°로 줌인, 장애물 또는 적의 공격 지점 쪽으로 최대 25° 회전.
  - 화면 위 판정 위치(장애물이나 칼끝을 화면에 투영한 점)에 원이 뜬다.
- **원 구성 (1080p 기준):** 가운데 버튼 아이콘(화살표) + 버튼을 둘러싼 목표 원(지름 120 px). 바깥 원은 지름 360 px에서 120 px로 2박자 동안 일정한 속도로 줄어든다. 두 원이 겹치는 순간이 목표 시점이다.
- **판정 창** (실제 시간, 속도 배율과 무관):
  | 결과 | 조건 |
  |---|---|
  | PERFECT | 목표 시점 ±60 ms 안에 정답 키 |
  | NORMAL | ±150 ms 안에 정답 키 (PERFECT 범위 밖) |
  | FAIL | 다른 키를 누름 / 목표 −300 ~ −150 ms 사이에 입력 / 목표 +150 ms까지 입력 없음 |
  - 목표 −300 ms보다 이른 입력은 무시한다(감점 없음).
- **타이밍 보정:** 설정의 "타이밍 보정" 값(−200 ~ +200 ms, 5 ms 단위, 기본 0)을 모든 판정 목표 시점에 더한다.
- **판정 문구:** 판정 직후 원 위치에 "PERFECT", "NORMAL", "FAIL"이 0.6초 동안 표시된다.
- 판정이 끝나면 채도와 FOV가 0.2초 동안 원래대로 돌아온다.
- 시간을 느리게 하는 슬로모션은 평소 판정에는 쓰지 않는다. **처형 동작과 윈드밀 마무리에만** 0.4초 동안 시간 배율 0.3으로 적용하고, 그동안 박자 시계와 음악은 멈추지 않는다(연출만 느려짐).

### 4.3 플레이어 (1인칭 전신)
- 전신 캐릭터 모델에 카메라를 눈높이(1.65 m)에 붙인다. 머리 메시는 플레이어 카메라에 그리지 않는다(그림자만 보임).
- 달릴 때는 손과 다리가, 파쿠르나 벽타기를 할 때는 시선에 따라 몸통과 다리가 화면에 보인다.
- 체력: **3**. 화면 왼쪽 위에 하트 3개로 표시한다. FAIL마다 1씩 줄고, 0이 되면 게임 오버.
- **속도감 효과:** `s ≥ 1.10`이면 화면 가장자리에 집중선이 나타나고, 그 세기는 `(s − 1.0) / 0.3`에 비례한다. 동시에 FOV가 최대 +5° 넓어진다.

### 4.4 장애물 (파쿠르)
- 결과와 관계없이 장애물 하나를 통과하는 데 걸리는 박자 수는 같다(**4박자**). 그래서 음악과 위치가 어긋나지 않는다. 결과에 따라 바뀌는 것은 동작 연출뿐이다.
- 장애물 사이의 간격은 최소 **4박자**.

| 장애물 | 키 | PERFECT | NORMAL | FAIL |
|---|---|---|---|---|
| 낮은 담, 수레, 항아리 더미 | ↑ | 깔끔하게 짚고 넘기 | 발이 걸려 휘청이며 넘기 | 부딪혀 뒤로 튕겨 남 → 허둥지둥 기어 넘기 |
| 지붕으로 뛰어오르기, 지붕 사이 건너뛰기 | ↑ | 멀리 뛰어 착지 | 처마 끝에 겨우 매달렸다 올라감 | 벽에 부딪혀 떨어졌다 다시 기어오름 |
| 낮은 처마, 빨랫줄 | ↓ | 미끄러져 통과 | 머리를 스치며 통과 | 걸려 넘어졌다 일어남 |
| 지붕에서 뛰어내리기 | ↓ | 착지 후 앞구르기 | 착지 후 비틀거림 | 엉덩방아 후 일어남 |
| 한쪽에 놓인 장애물 | ← / → | 가볍게 옆으로 피하기 | 어깨를 스치며 피하기 | 부딪혀 튕겨 났다 다시 달림 |
| 왼쪽/오른쪽 벽 | ← / → | 벽타기로 3 m 달려 넘어감 | 짧게 벽을 차고 넘어감 | 벽에 부딪혀 떨어졌다 기어오름 |

- FAIL: 체력 −1, 속도 ×0.8 (최소 1.00). 음악은 멈추지 않고 되감지도 않는다.

### 4.5 적과의 전투
- 적이 나타나면 자동 이동을 멈추고 전투한다. 박자 시계와 음악은 계속 간다. 전투가 끝나면 다음 마디(4박자 단위) 첫 박에 다시 달린다.
- 적의 공격은 박자 위에 놓인다. 공격이 올 때 무기에 **잔상 효과**(트레일과 반투명 잔상 2~3개)가 남고, 카메라는 칼끝을 따라 움직인다.
- 원 하나가 공격 하나다. 원이 겹쳐 보일 때는 목표 시점이 빠른 순서로 판정한다.

| 공격 | 키 | PERFECT | NORMAL | FAIL |
|---|---|---|---|---|
| 가로베기 | ↓ | 숙여 피하기 (칼이 머리 위로 지나감) | 아슬아슬하게 숙임 | 맞음 (화면 흔들림 + 붉은 테두리) |
| 내려베기 / 찌르기 | ← 또는 → (표시된 쪽) | 옆으로 비키기 | 옷깃이 스치며 비킴 | 맞음 |
| 올려베기 | ↑ | 칼로 받아 막기 | 막았지만 밀려남 | 맞음 |
| **마무리** | ↑ | 처형: 지붕 위 → 발차기로 떨어뜨리기 / 땅 위 → 칼 뺏어 베기, 또는 적의 칼을 쥔 손째로 적을 찌르기 | 밀쳐 쓰러뜨리기 | 맞음 |

- 방어 판정 FAIL 또는 마무리 FAIL: 체력 −1, 속도 ×0.8. 다음 마디부터 **그 적의 첫 공격부터 다시** 한다.
- 적 종류:
  | 적 | 무기 | 공격 수 (마무리 제외) | 공격 간격 |
  |---|---|---|---|
  | 칼 든 포졸 | 환도 | 2 | 2박자 |
  | 창 든 포졸 | 창 | 2 | 2박자 |
  | 무사 (최종) | 환도 | 5 (연속 콤보) | 1~2박자 섞어서 |
- 적의 동작: 대기, 다가오기, 공격 종류별 동작, 막힘/빗나감, 피격, 쓰러짐, 발차기에 맞아 지붕에서 떨어짐.
- 연속 공격은 여러 클립을 Animator에서 이어 붙이고, 카메라 흔들림과 효과로 박진감을 더한다(6장).

### 4.6 포위 전투 (스테이지 중반, 마당)
- 적 5명(칼 3, 창 2)이 반지름 4 m 원으로 둘러싼다.
- **1단계 (순차 공격):** 5명이 1박자 간격으로 한 명씩 공격한다. 카메라는 공격하는 적 쪽으로 0.2초 안에 돈다.
- **2단계 (동시 공격):** 2~3명이 같은 박자에 공격하는 일이 3번 있다. 원 하나, 키 하나로 판정하며 한 번 성공하면 모두 피한다. 이때 카메라가 낮게 깔리고 칼들이 머리 위로 지나간다.
- **3단계 (윈드밀 마무리):** 반 박자 간격으로 화살표 4개가 이어진다(예: ← ↑ → ↓). 4개 모두 NORMAL 이상이면 윈드밀 발차기로 5명을 한꺼번에 날려 보낸다. 이때 슬로모션과 카메라 360° 회전이 들어간다.
- 1·2단계 FAIL: 체력 −1. 전투는 다시 하지 않고 이어 간다. 3단계 FAIL: 체력 −1, 다음 마디에 3단계만 다시 한다.

### 4.7 승리 / 패배 조건
- **승리:** 마지막 무사를 쓰러뜨리면 "스테이지 클리어" → 결과 화면.
- **패배:** 체력이 0이 되면 "게임 오버" → 결과 화면.
- 점수: PERFECT 300점, NORMAL 100점, FAIL 0점. 콤보는 FAIL 없이 이어진 판정 수.
- 랭크 (클리어했을 때만, 전체 판정 중 PERFECT 비율 기준): S ≥ 90% 그리고 FAIL 0 / A ≥ 75% / B ≥ 50% / C 그 밖. 게임 오버면 "-".

### 4.8 화면 (UI)
- 모든 문구를 따옴표로 정확히 적는다(테스트가 문구를 비교한다). 폰트는 맑은 고딕.
- **타이틀:** 제목 "Rhythm-Action-Game", 버튼 "시작", "설정", "종료".
- **설정:** "타이밍 보정" 슬라이더(−200 ~ +200 ms, 값 표시 예: "+15ms"), "음량" 슬라이더(0~100, 기본 80), 버튼 "돌아가기". 설정값은 PlayerPrefs에 저장한다.
- **플레이 HUD:** 왼쪽 위 하트 3개, 오른쪽 위 속도 "x1.00", 그 아래 점수, 가운데 아래 "콤보 12" (콤보가 2 이상일 때만 표시).
- **판정:** "PERFECT", "NORMAL", "FAIL".
- **일시정지 (Esc):** "일시정지", 버튼 "계속", "타이틀로". 일시정지 중에는 음악과 박자 시계도 멈춘다.
- **결과:** 제목 "스테이지 클리어" 또는 "게임 오버", "PERFECT 18", "NORMAL 5", "FAIL 2", "최고 속도 x1.30", "점수 5900", "랭크 A", 버튼 "다시 하기", "타이틀로".

### 4.9 맵 / 레벨
- 경로는 웨이포인트로 만든 하나의 곡선 경로이며, 플레이어는 그 위를 자동으로 이동한다. 전체 길이는 약 **650 m**(달리기 구간 약 260박자 × 2.5 m).
- 구간 (박자는 달리기 + 전투를 합친 대략값, 재도전이 없을 때 기준):

| # | 구간 | 박자 | 내용 |
|---|---|---|---|
| 1 | 마을 골목 | 0–64 | 연습용 장애물 4개 (↑ 수레, ↓ 빨랫줄, ← 항아리 더미, ↑ 낮은 담) |
| 2 | 돌담과 지붕 오르기 | 64–128 | 장애물 5개 (담, 지붕으로 뛰어오르기, 벽타기 2) + 칼 든 포졸 1 |
| 3 | 기와지붕 | 128–208 | 장애물 5개 (지붕 건너뛰기 3, 낮은 처마 1, 뛰어내리기 1) + 창 든 포졸 1 (지붕 위 → 발차기) + 칼 든 포졸 1 |
| 4 | 마당 포위 전투 | 208–256 | 4.6의 포위 전투 |
| 5 | 궁궐 담 | 256–320 | 장애물 6개 + 창 든 포졸 1 |
| 6 | 성문 위 결전 | 320–352 | 무사 1 (공격 5 + 마무리) |

- 합계: 장애물 20개, 일반 적 4명, 포위 전투 5명, 무사 1명.
- 기와지붕 높이 4~6 m, 지붕 사이 간격 3~5 m, 경로 폭 3 m.
- 스테이지 구성(장애물·적의 박자 위치)은 데이터 파일(차트) 하나로 관리한다.

## 6. 기술 결정 (Claude 제안, 변경 가능)
- 씬은 코드(Editor 스크립트 `SceneBuilder`)로 생성 → 사람이 Unity를 열지 않아도 Claude가 재현할 수 있다.
- GLB 임포트: `com.unity.cloud.gltfast`, 캐릭터는 FBX + Humanoid. Mixamo 동작은 Humanoid로 리타깃한다.
- 한글 UI: Windows `맑은 고딕` 동적 폰트.
- 박자 시계: `AudioSettings.dspTime` 기준. 메트로놈 소리는 `AudioClip.Create`로 코드에서 만든다(마디 첫 박 강세).
- 차트(장애물·적 배치): JSON 또는 ScriptableObject. 단위는 박자.
- 툰 셰이딩: URP 커스텀 셰이더(2~3단계 명암) + 뒤집은 외곽선 메시.
- 회색 화면: URP Volume의 Color Adjustments(채도). 집중선: 화면 공간 파티클 또는 UI 셰이더.
- 잔상: TrailRenderer + 무기 메시 복제본을 반투명하게 0.1초 간격으로 남겼다가 사라지게 한다.
- 맞물리는 동작(처형, 칼 뺏기): 플레이어 클립과 적 클립을 같은 시작 박에 재생하고, 시작 위치·방향을 미리 맞춘다. 순간 슬로모션과 카메라 흔들림으로 이음새를 가린다.
- 연속 공격: Animator 상태를 공격별로 나누고 0.1~0.15초 크로스페이드로 잇는다(언리얼 몽타주 대체).
- 1인칭 몸: 머리 뼈 아래 메시는 `ShadowsOnly`, 카메라는 머리 뼈 위치를 부드럽게 따라간다.
