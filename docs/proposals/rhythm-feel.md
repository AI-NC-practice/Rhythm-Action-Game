### 1.3 맞춤곡 (유료)
- Suno Pro(연간 결제 기준 월 ₩12,000)로 **"퓨전 국악 액션, 태평소·장구·드럼, 정확히 120 BPM, 보컬 없음, 3분 30초"**를 만들 수 있다.
  박자·길이·분위기를 게임에 딱 맞출 수 있는 유일한 방법이다. 결제는 사용자가 정한다.

### 1.4 빠르기가 120이 아닌 곡을 고르면
두 가지 방법이 있다. 곡을 고른 뒤 정한다.
- **(가) 게임 BPM을 곡에 맞춘다** (예: 130 또는 160). 판정·연출은 모두 "박" 단위라 코드는 GameConfig 값 하나로 바뀐다. 1박 이동 거리(2.5 m)는 그대로 두고 달리기 속도가 빨라진다. GDD-beta에 "기준 BPM = 곡 BPM"으로 적는다.
- **(나) 곡의 빠르기만 바꾼다** (음 높이 유지). 130 → 120(−8%)은 자연스럽다. 160 → 120(−25%)은 소리가 뭉개져서 권하지 않는다.

## 2. 박자감 연출 (리듬게임 참고)

| 참고 게임 | 가져올 점 |
|---|---|

| Hi-Fi Rush | 공격·발소리·배경 물체·화면 효과가 **전부 박에 맞춰** 움직인다. 공격 소리를 박에 맞춰 울린다 |
| Crypt of the NecroDancer | 화면 아래 **박자 막대**와 박마다 뛰는 심장. 다음 박이 언제 오는지 눈으로 보인다 |
| 리듬 세상 (Rhythm Heaven) | **소리 신호:** 적이 "쉭–쉭–" 하고 리듬을 들려준 뒤 내가 같은 리듬으로 받는다(주고받기) |
| Thumper, Sayonara Wild Hearts | 판정 성공 때 화면이 박에 맞춰 크게 번쩍이고 카메라가 튄다 |

### 2.1 소리
1. **히트사운드 (가장 효과 큼):** 키를 누른 순간 북/장구 "딱" 소리. PERFECT는 맑고 큰 소리, NORMAL은 작은 소리, 빈 입력은 아주 작게. 지연 없이 바로 울린다(박에 늦게 맞추지 않는다).
   판정 효과음(칼 부딪힘 등)은 그대로 두고, 히트사운드를 그 앞에 겹친다.
2. **판정 예고음:** 판정 원이 나타날 때 박마다 작은 "틱"(2박 전, 1박 전). 곡이 시끄러워도 언제 누를지 귀로 알 수 있다. 설정에서 끌 수 있게 한다.
3. **적의 리듬 신호 (주고받기):** 적이 공격 전에 칼을 휘두르는 소리로 리듬을 먼저 들려준다(예: "쉭–쉭쉭"). 플레이어는 같은 리듬으로 막는다. 무사 연속 콤보에 특히 잘 맞는다.

### 2.2 화면
4. **박 펄스:** 박마다 판정 원 테두리, HUD(속도·점수), 화면 가장자리 비네트가 살짝 커졌다 돌아간다(마디 첫 박은 더 크게). 원이 없을 때도 박을 느낄 수 있다.
5. **카메라·몸 박자:** 달리기 발걸음과 카메라 흔들림을 박에 맞춘다(1박 = 한 걸음). 등불·깃발·적의 대기 자세도 박에 맞춰 흔들린다(Hi-Fi Rush 방식).
6. **박자 막대 (선택):** 화면 아래에 다음 판정까지 남은 박을 보여 주는 얇은 막대. 판정 원과 겹치는지 보고 정한다.
7. **연속 PERFECT 강조:** 콤보가 이어지면 박 펄스가 점점 커지고, 8콤보마다 마디 첫 박에 화면이 한 번 번쩍인다.

## 3. 차트: 정박만 타지 않는다

- 1박을 쪼갠 **반 박(8분) 패턴**과 **엇박**을 쓴다. 판정 간격은 최소 반 박(0.25초, 120 BPM 기준)으로 한다(윈드밀과 같음).
- 패턴 예 (숫자 = 마디 안 박 위치, 0부터):

| 이름 | 위치 | 느낌 | 쓰는 곳 |
|---|---|---|---|
| 정박 | 0, 1, 2, 3 | 기본 | 1~2챕터 달리기 |
| 따닥 | 0, 0.5 | 짧은 두 번 | 장애물 연속, 일반 적 2연타 |
| 엇박 | 0.5, 1.5 | 박 사이 | 지붕 위 추격, 화살 |
| 당김 (싱코페이션) | 0, 1.5, 3 | 3-3-2 느낌 | 포위 전투 1단계 |
| 몰아치기 | 0, 0.5, 1, 1.5 | 4연타 | 윈드밀(지금과 같음), 무사 3단계 |
| 쉼 뒤 강타 | 2.5, 3 | 숨 고르고 "따-쾅" | 처형·마무리 직전 |

- **곡을 듣고 찍는 차트:** 곡을 정한 뒤 곡의 실제 드럼 위치(킥·스네어·장구 강세)를 분석해서 판정을 그 자리에 놓는다. 그러면 히트사운드와 곡이 함께 울린다. 분석 결과를 사람이 다듬는다.
- **난이도 흐름:** 1~2챕터는 정박 위주 → 3~4챕터에 따닥·엇박 → 포위·무사전에 당김·몰아치기.
- 판정 수와 챕터 구조는 지금과 비슷하게 유지한다(전체 65~75개). 판정 창(PERFECT ±90 ms, NORMAL ±240 ms)은 그대로 둔다. 반 박 간격에서 NORMAL 창이 겹치면 지금처럼 가까운 원으로 판정한다(B30).

## 4. 진행 순서 (승인되면 작업으로 나눈다)

1. **음악 결정** — 사용자가 후보를 듣고 고르거나 Suno 맞춤곡을 정한다 (BPM이 120이 아니면 1.4의 가/나).
2. **히트사운드 + 판정 예고음 + 박 펄스** (2.1의 1·2, 2.2의 4) — 가장 효과가 크다. 곡과 따로 만들 수 있어 먼저 해도 된다.
3. **차트 다시 찍기** — 곡 분석 → 반 박·엇박 패턴 → 테스트.
4. **나머지 연출** (2.1의 3, 2.2의 5~7) — 테스트 빌드로 확인 후.

## 5. 사용자가 정할 것

## 6. 추가 피드백 (2026-11-14, 히트사운드 테스트 빌드 뒤)

사용자 의견
- 악보를 맞출 때 나는 소리가 **하나의 박자처럼** 느껴지면 좋겠다. 지금은 노래와 따로 논다.
- 박자를 쪼개 노드를 놓는 것도 좋다. 곡을 더 생동감 있게.
- 속도가 빨라지는 건 좋은데, **노래가 같이 기괴해진다.** 줄일 방법은?

### 6.1 히트사운드가 따로 노는 이유와 해결
| 이유 | 해결 |
|---|---|
| 판정 위치가 곡의 드럼 위치와 상관없이 박 격자에만 있다. 게다가 지금 곡(#197)은 3박 느낌이라 4박 격자와 어긋난다. | 4/4 드럼이 뚜렷한 곡으로 바꾸고, **곡의 실제 타격 위치에 판정을 놓는다**(3장). 히트사운드가 곡의 드럼과 같이 울린다. |
| 사람 손은 박보다 조금 이르거나 늦다. 누른 순간 바로 울리니 소리도 박에서 어긋난다. | **박 맞춤(퀀타이즈):** 목표보다 **이르게** 눌렀고 PERFECT 창(±90 ms) 안이면, 소리를 목표 박 시각에 정확히 예약해 울린다(Hi-Fi Rush 방식). 늦게 누르면 지금처럼 바로 울린다(지나간 박으로 돌아갈 수 없음). NORMAL 창의 이른 입력(최대 240 ms 이름)은 기다리면 굼떠 보이므로 바로 울린다. |
| 소리가 곡과 다른 악기·음 높이다. | 곡을 정하면 곡의 조(key)와 악기에 맞춰 소리를 다시 만든다(곡의 장구·북 소리에 가깝게, 음 높이를 곡의 으뜸음에 맞춤). 히트사운드에 곡과 같은 잔향을 살짝 넣는다. |

### 6.2 박 쪼개기
3장 그대로 진행한다. 곡을 정한 뒤 곡의 드럼(킥·스네어·장구 강세)을 분석해 정박·반 박·엇박 위치를 고르고, 앞 챕터는 정박 위주 → 뒤로 갈수록 쪼갠 박을 늘린다.

### 6.3 속도가 빨라질 때 노래가 기괴해지는 이유와 해결
| 이유 | 해결 |
|---|---|
| **음 높이 보정이 빠져 있다.** GDD 4.1은 "음 높이는 AudioMixer Pitch Shifter로 1/s만큼 보정"이라고 정했지만 아직 구현되지 않았다. 지금은 s = 1.30이면 음이 약 4.5반음 올라간다(다람쥐 소리). | **GDD 4.1대로 음 높이 보정을 넣는다.** Music 그룹에 Pitch Shifter를 걸고 피치를 1/s로 둔다 → 빨라져도 음 높이는 그대로. (GDD 그대로라 기획 변경 아님.) |
| PERFECT마다 그 순간 속도가 0.05씩 바뀐다. 음이 울리는 도중에 빠르기와 높이가 툭툭 바뀐다. | **속도는 다음 마디 첫 박에 바꾼다** (GDD-beta 변경 필요). 쌓인 변화를 마디 단위로 한 번에 적용하면 곡의 흐름이 끊기지 않는다. 판정 원·이동도 같은 순간에 바뀌어 박자가 어긋나지 않는다. |
| (보정을 넣어도) Unity의 Pitch Shifter는 음질이 완벽하지 않다(약간 울렁이는 소리). | 위 두 가지로 부족하면: 곡을 빠르기별(1.00, 1.10, 1.20, 1.30)로 미리 음 높이 그대로 늘여 만든 파일을 두고, 마디 첫 박에 같은 위치로 갈아 끼운다. 음질이 가장 좋지만 파일이 4배라 마지막 수단으로 둔다. |

### 6.4 순서 제안
1. **음 높이 보정 + 마디 단위 속도 변경** (곡과 상관없이 바로 효과, 지금 곡으로도 확인 가능)
2. **히트사운드 박 맞춤** (이른 PERFECT 입력은 목표 박에 울림)
3. **곡 선택** → 곡에 맞춘 히트사운드 음색 + 곡의 드럼 위치로 차트 다시 찍기(쪼갠 박 포함)
